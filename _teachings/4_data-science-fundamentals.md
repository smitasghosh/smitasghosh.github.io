## Course Overview

This course introduces the fundamental concepts and methods of data science and machine learning. Students learn how to work with data, visualize and analyze datasets, and apply machine learning methods to practical problems.

Topics include:

- Introduction to Data Science
- Python for Data Science
- Data Collection and Importing Data
- Data Visualization
- Introduction to Machine Learning
- Linear Regression
- Linear Classification
- Distance Measures
- Supervised and Unsupervised Learning
- K-Nearest Neighbors (KNN)
- Decision Trees
- Random Forests
- Feature Selection
- Clustering
- Data Science Ethics

## Prerequisites

- Introductory programming
- Discrete mathematics
- Probability and statistics
