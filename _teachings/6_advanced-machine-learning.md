## Course Overview

This course builds on introductory machine learning and focuses on modern learning methods and neural architectures. Students study the progression from foundational neural models to deep learning, representation learning, and transformer-based architectures, along with reinforcement learning and responsible machine learning.

Topics include:

- Machine Learning Review
- Model Selection and Evaluation
- Introduction to Deep Learning
- Perceptron and Linear Neural Models
- Neural Networks and Backpropagation
- Convolutional Neural Networks (CNNs)
- Representation Learning and Embeddings
- Attention Mechanisms
- Transformers
- Reinforcement Learning
- Ethics in Machine Learning

## Prerequisites

- Introductory machine learning
- Probability and statistics
- Linear algebra
- Programming experience
