## Course Overview

This course introduces fundamental concepts in computer science and programming. Students develop computational thinking and problem-solving skills through programming exercises and hands-on labs, while also exploring applications and societal aspects of computing.

Topics include:

- Introduction to Programming
- Python Basics
- Variables and Data Types
- Console Input and Output
- Expressions and Operators
- Branching and Conditionals
- Loops
- Functions and Scope
- Lists and Dictionaries
- Strings
- Classes and Object-Oriented Programming
- File Input and Output
- Recursion
- Introduction to C++
- Applications of Computing
- Artificial Intelligence
- Privacy and Social Impact of Computing
- Computing in Science and Other Disciplines
