## Course Overview

This course introduces the specification, implementation, and analysis of fundamental data structures. Students learn how to select and implement appropriate data structures and apply them to common searching, sorting, and problem-solving tasks.

Topics include:

- Stacks
- Queues and Deques
- Trees and Tree Representations
- Binary Trees
- Tree Traversals
- Binary Search Trees
- Heaps
- Priority Queues
- B-Trees
- Maps and Multimaps
- Sorting Algorithms
- Recursive Sorting
- Heap Sort
- Sequential Search
- Binary Search
- Hash Tables
- Open-Address Hashing
- Chained Hashing
- Graphs

## Prerequisites

- Introductory programming
- Object-oriented programming
- Basic algorithmic problem solving
