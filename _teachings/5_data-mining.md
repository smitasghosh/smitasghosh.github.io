## Course Overview

This course introduces fundamental concepts and techniques in data mining, with emphasis on discovering useful patterns from structured and unstructured data. Students study methods for association analysis, information retrieval, text and web mining, anomaly detection, and related data mining applications.

Topics include:

- Introduction to Data Mining
- Association Rule Mining
- SQL for Data Analysis
- Regular Expressions
- Information Retrieval
- Vector Space Models
- Latent Semantic Indexing
- Topic Modeling
- Link Analysis
- Anomaly Detection
- Other Data Mining Concepts and Applications

## Prerequisites

- Programming experience
- Discrete mathematics
- Probability and statistics
- Introductory data science or machine learning recommended
